# ZedLabs

A small senior engineering partnership with people in the US and Latin America. We build custom software and AI for growing businesses, modernize the systems they already run, and hand it over with the code, the documentation and a repeatable way to run it.

**What we do**

- **Custom software, built and handed over.** Reporting and workflow tools, customer portals, internal applications, and modern replacements for legacy systems. Scoped and priced from a written estimate.
- **AI in the systems you already run.** Agents, extraction, retrieval and assistants added to existing software, with evaluation, logging and human review built in.
- **Engineers for your team.** Senior engineers in the US or nearshore in Costa Rica and Guatemala, working US Central hours in your repo.
- **Architecture and coaching.** Solution design for teams without an architect, and hands-on coaching in modern delivery and AI-assisted development.

**How we work**

A principal-level engineer leads each engagement and stays through delivery. We build with AI coding agents every day, backed by code review, automated tests and security checks. Everything we build is yours: your repo, your cloud, your documentation.

**Stack we work in daily**

TypeScript / Node.js · React / Next.js · React Native / Flutter · .NET · Python · PostgreSQL / SQL Server / MongoDB / Redis · GraphQL · Azure / AWS · Docker · Anthropic / OpenAI / MCP
